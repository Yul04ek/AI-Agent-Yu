# web-scraping-econ references

1. **FRED** (Federal Reserve Economic Data): https://fred.stlouisfed.org/ - offers CSV and JSON downloads for U.S. economic indicators.
2. **OECD Data**: https://data.oecd.org/ - many datasets expose API endpoints and bulk downloads.
3. **IMF Data**: https://www.imf.org/en/Data - includes SDMX/JSON services for global macro data.
4. **requests** (standard scraping library): https://docs.python.org/3/library/urllib.request.html - prefer when avoiding third-party dependencies.
5. **BeautifulSoup** (if justified): https://www.crummy.com/software/BeautifulSoup/bs4/doc/ - for parsing HTML tables when structured endpoints are unavailable.
6. **robots.txt checker**: https://www.robotstxt.org/ - remind users to validate before scraping.
